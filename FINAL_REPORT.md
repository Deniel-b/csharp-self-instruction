```json

  "type": "code",

  "starterCode": "Начальный код",
  "entryPoint": { "class": "Solution", "method": "Main" },
  "constraints": { 
    "timeLimitMs": 5000,
    "memoryLimitMb": 128
  },
  "tests": [
    {
      "visibility": "visible",
      "input": "тестовые данные",
      "expectedOutput": "ожидаемый результат"
    }
  ]
}
```

## 🚀 Как использовать

1. **Студент изучает теорию** на странице раздела
2. **Студент видит вопросы для самопроверки** (Quiz)
3. **Студент выполняет практическое задание** (Code Task)
4. **Встроенный компилятор проверяет решение** автоматически
5. **Видны результаты видимых тестов**, скрытые проверяются при отправке
