# Практические задания на код (Code Tasks)

## Обзор

Каждый раздел курса теперь содержит **практическое задание на написание кода** (Code Task), которое проверяется встроенным компилятором и автоматическими тестами.

## Структура задания

```json
{
  "id": "unique-task-id",
  "type": "code",
  "title": "Название задания",
  "prompt": "Описание что нужно сделать",
  "starterCode": "Начальный код для помощи",
  "entryPoint": {
    "class": "Solution",
    "method": "MethodName",
    "signature": ""
  },
  "constraints": {
    "timeLimitMs": 5000,
    "memoryLimitMb": 128,
    "disallow": []
  },
  "tests": [
    {
      "id": "test-1",
      "visibility": "visible",
      "input": "input data",
      "expectedOutput": "expected output"
    }
  ]
}
```

## Компоненты

### 1. **Prompt (Описание)**
Четкое описание того, что нужно реализовать.

Пример:
> "Напишите программу, которая выводит строку 'Hello, World!' в консоль."

### 2. **Starter Code (Начальный код)**
Шаблон кода для помощи студентам.

```csharp
public static void Main()
{
    // Ваш код здесь
}
```

### 3. **Entry Point (Точка входа)**
Указывает компилятору, какой класс и метод вызывать для запуска.

- **class**: имя класса (обычно "Solution")
- **method**: имя метода для вызова

### 4. **Test Cases (Тестовые случаи)**
Автоматические тесты для проверки решения.

#### Видимые тесты (`visibility: "visible"`)
- Показываются студенту до отправки
- Помогают понять требования
- Пример: `input: "10 20"` → `output: "15"`

#### Скрытые тесты (`visibility: "hidden"`)
- Проверяют граничные случаи
- Запускаются после отправки
- Пример: `input: "100 200"` → `output: "150"`

### 5. **Constraints (Ограничения)**
Защита от бесконечных циклов и чрезмерного использования памяти.

- `timeLimitMs`: 5000ms (5 секунд)
- `memoryLimitMb`: 128MB памяти

## Примеры заданий

### Пример 1: Переменные и константы
```
Задание: Объявите переменную целого типа x, установите её значение на 42 и выведите в консоль.

Тест 1: "" → "42"
```

### Пример 2: Методы
```
Задание: Напишите метод CalculateAverage, который принимает два целых числа и возвращает их среднее.

Тест 1 (видимый): "10 20" → "15"
Тест 2 (видимый): "5 15" → "10"
Тест 3 (скрытый): "100 200" → "150"
```

### Пример 3: Классы и объекты
```
Задание: Создайте класс Rectangle с конструктором и методом Area() для расчёта площади.

Тест 1 (видимый): ширина=5, высота=4 → "20"
Тест 2 (скрытый): ширина=10, высота=3 → "30"
```

## Версия в JSON

Все задания находятся в файле `/src/content.v2.json` в структуре:

```
chapters[] 
  → sections[] 
    → pages[] 
      → tasks[] (type="code")
        → tests[]
```

## Как работает компилятор

1. **Валидация** - проверяет опасные операции (System.IO, System.Net и т.д.)
2. **Компиляция** - использует Roslyn для компиляции C# кода
3. **Выполнение** - запускает метод с тестовыми данными
4. **Проверка** - сравнивает вывод с ожидаемым результатом

## Подсказки (Hints)

Каждое задание содержит подсказки для помощи:

```json
"hints": [
  "Начните с написания основного кода.",
  "Убедитесь, что ваш код обрабатывает все тестовые случаи.",
  "Проверьте, правильно ли выглядит вывод."
]
```

## Оценка (Scoring)

- **points**: 5 баллов за успешное решение
- **partial**: false (всё или ничего)

## Этапы добавления нового задания

1. Добавить entry в `code_tasks` словарь в `add_code_tasks.py`
2. Указать `id`, `order`, `title`, `prompt`, `starter`
3. Добавить `entry_point` (class/method)
4. Добавить `tests` с видимыми и скрытыми случаями
5. Запустить скрипт `python add_code_tasks.py`
6. Проверить компиляцию `dotnet build`
